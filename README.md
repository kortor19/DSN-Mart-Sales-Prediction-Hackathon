# DSN-Mart-Sales-Prediction-Hackathon
Build a machine learning model that predicts product-store sales for DSN Mart, a retail chain with operations across Nigeria

# Project Brief
DSN Mart operates a chain of stores across Nigeria, from small corner shops to flagship
hypermarkets, spread across major urban centres, state capitals, and smaller towns. Like any
growing retail business, DSN Mart wants to understand what drives sales at the product level across
its different store formats and locations, so it can plan stock, pricing, and store investment more
intelligently.
